# Requirements

- `C++ compiler`
- `cmake`

# Build Instructions

1. Make a build directory

```bash
mkdir build 
```

2. move to the build directory
```bash
cd build 
```

3. Build ObjectScan
```bash
cmake ..
```

4. Make ObjectScan
```bash
make 
```
